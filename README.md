# DSA in Python: Lists and Strings

Data structures and algorithms practice on lists and strings in Python.

## What's Inside

- List and string problems and solutions

## Tech Stack

Python, Jupyter Notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install jupyter`
3. Open the notebook with `jupyter notebook` and run the cells in order
